ANNOTATION

Skakovskyi A.V., Symets I.I. (supervisor). Mobile application for personalized workout and nutrition planning. Bachelor qualification thesis, specialty 121 "Software Engineering". – Lviv Polytechnic National University, Lviv, 2026. – 149 p.
The objective of the work is the development of the cross-platform mobile application Athlo, which combines workout and nutrition planning within a single environment and provides tools for workout logging, template management, and progress tracking.
The relevance stems from the interconnection of workouts and nutrition as components of a common process, as most existing fitness applications support only individual aspects of this process: workout applications do not track nutrition, while calorie trackers poorly reflect physical activity.
The application is intended for devices running the iOS and Android operating systems.
The development uses the TypeScript programming language, React Native with the Expo platform for the client side, NestJS on top of Node.js for the server side, and the relational database PostgreSQL.
The system is based on a client-server architecture with a three-layer server codebase divided into four domains, which separates the presentation, business logic, and data layers and supports scalability.
The application provides authentication, profile management with anthropometric data, structured workout logging with automatic detection of personal records, a nutrition journal with calculation of calorie content and macronutrients, an exercise catalog, statistics and achievements, and social interaction through friends and template sharing.
The software is stable owing to comprehensive testing of both architectural layers: functional, interface, and integration checks together with security tests confirmed compliance with the requirements, and the detected defects were eliminated.
